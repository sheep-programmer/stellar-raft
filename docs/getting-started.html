GETTING STARTED

开始使用

整套系统是纯静态资源：一个样式入口、一份编译好的组件 bundle、一段星场脚本。不需要构建工具，把仓库放上任何静态服务器（或直接 node server/server.js）就能用。

STEP 1 · TOKENS

链接唯一的样式入口

消费者只链 styles.css 这一个文件。它 @import 全部 tokens/（字体、色彩、字号、间距、效果、主题），同时带来 .sr-glass 等工具类与所有 @keyframes。此后一切样式都写 var(--token)，不要硬编码新颜色。

index.html
<!-- 相对路径按你的页面位置调整；本文档站在 docs/ 下，故为 ../ -->
<link rel="stylesheet" href="../styles.css">

<!-- 深空舞台：背景永远不是纯平色 -->
<body style="background: var(--bg-deepspace); color: var(--text-1); font-family: var(--font-sans)">
STEP 2 · STARFIELD

铺上活的星场

引入 assets/starfield.js 后即可使用自注册的 <sr-starfield> 元素：三层视差星层、恒星温度配色、衍射亮星、银河薄雾与偶发流星——全部感知 prefers-reduced-motion，并在黎明主题下自动收敛。同文件还导出 window.SRConnect()，生成有机连接曲线（连接永远是曲线，不是直线箭头）。

starfield + 有机连接
<script src="../assets/starfield.js"></script>

<!-- 定好位（absolute/fixed），星场自己铺满 -->
<sr-starfield density="1" warm="0.12"></sr-starfield>

// SVG path d：两星之间的有机弧线（bow 为弯曲量）
const d = window.SRConnect(x1, y1, x2, y2, bow);
STEP 3 · COMPONENTS

加载组件 bundle 与命名空间

组件编译在 _ds_bundle.js，挂载于全局命名空间 window.StellarRaftDesignSystem_2866af。运行时依赖 React 18 UMD；静态页写 JSX 可加 Babel Standalone（生产环境请预编译）。

依赖顺序：React → Babel → Lucide → bundle
<script src="https://unpkg.com/react@18.3.1/umd/react.production.min.js"></script>
<script src="https://unpkg.com/react-dom@18.3.1/umd/react-dom.production.min.js"></script>
<script src="https://unpkg.com/@babel/standalone@7.29.0/babel.min.js"></script>
<script src="https://unpkg.com/lucide@latest/dist/umd/lucide.min.js"></script>
<script src="../_ds_bundle.js"></script>

STEP 4 · ICONS

图标：只用 Lucide

品牌铁律：禁 emoji，禁把 unicode 字符当图标。唯一图标来源是 Lucide（CDN），线性 ~1.6px 描边。默认态星蓝约 70% 不透明度，悬停 / 激活转暖金——Icon / IconButton 已封装这套行为。

两种消费方式
// React：走组件（推荐，行为与着色统一）
<Icon name="satellite" size={20} />
<IconButton name="search" title="搜索" />

<!-- 纯静态 HTML：data-lucide + createIcons -->
<i data-lucide="telescope"></i>
<script>lucide.createIcons({ attrs: { 'stroke-width': 1.6 } });</script>
STEP 5 · THEMES

双主题：深空 / 黎明

系统深色优先；浅色主题「黎明 Dawn」以 token 作用域交付（tokens/themes.css）。只要你的样式全部走 var(--token)，切主题就是改一个属性——语义不变：金 = 奖励，星蓝 = 结构。星场与 memoryColor 会在运行时读取主题自动适配。

theme.js · 切换 + 记忆
// 开启黎明
document.documentElement.dataset.theme = 'dawn';
// 回到深空（移除属性即回默认）
delete document.documentElement.dataset.theme;

// 持久化：进页面先读，再写 <html data-theme>（放 <head> 内联防闪白）
try {
  if (localStorage.getItem('theme') === 'dawn')
    document.documentElement.dataset.theme = 'dawn';
} catch (e) {}
NON-NEGOTIABLES

接入前的自查清单

  • 色相预算 ≤ 3–4：深空蓝黑 + 星蓝（结构）+ 金（仅奖励 / 点亮 / 掌握）。金色绝不铺开用。
  • 所有颜色、间距、圆角、字号都来自 token —— 不新造十六进制。
  • 面板走玻璃拟态（.sr-glass / GlassPanel），边框只用发丝线，工具条用胶囊。
  • 动效缓慢克制，统一 var(--ease-flight)；点亮时刻是唯一的高能瞬间；尊重 prefers-reduced-motion。
  • 文案中文优先，克制、精确、略带诗意——展示隐喻，不解说隐喻。
