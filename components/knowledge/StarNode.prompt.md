A single knowledge star for the star-map canvas. Encodes meaning, not decoration: brightness/color = memory strength, size = importance, breathing = alive. Position it absolutely from the parent.

```jsx
<StarNode strength={0.9} importance={1.4} label="贝尔不等式" selected
          style={{ left: '40%', top: '55%' }} />
```

Warm gold core appears once strength ≥ 0.82 (mastered). Pair with `MemoryBar` and organic connection paths (`SRConnect`).
