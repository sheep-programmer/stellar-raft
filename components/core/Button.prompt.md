Pill text button. `primary` is the warm-gold reward button — reserve it for ignition / confirm ("点亮这颗星"). `secondary` is the glass default; `ghost` is transparent/tertiary.

```jsx
<Button variant="primary" icon="zap" glow>点亮这颗星</Button>
<Button icon="plus">新建星</Button>
<Button variant="ghost">取消</Button>
```

Hover brightens/lifts, press shrinks (scale .97). Optional leading/trailing Lucide icon.
