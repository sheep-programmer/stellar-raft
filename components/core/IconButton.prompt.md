Ghost icon control with the brand's signature tint: star-blue idle, warm gold + faint glow on hover/active, gentle shrink on press. Use for toolbars, capsule tools, sidebar nav, editor controls.

```jsx
<IconButton name="search" title="搜索" />
<IconButton name="list" active title="列表视图" />
<IconButton name="rotate-ccw" size="lg" title="复位" />
```

`active` keeps it gold (current view / selected tool). Requires Lucide CDN.
