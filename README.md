## 这是什么

**星图 Stellar Raft** 是一款面向大学生（尤其理工科）的知识笔记应用的**品牌与设计系统**。

它把知识可视化成一片会呼吸的深空：每则笔记是一颗星，记得越牢越亮，久不回望便冷却、变暗，直至熄灭。

本仓库同时是三样东西：

- **设计系统的唯一真源** — 设计令牌 + 18 个组件原语 + 零构建文档站
- **可交互的完整应用** — 星图 / 列表 / 编辑器 / 复习 / 收件箱 / 漫游 … 全部真实可用，桌面 / 平板 / 手机三档断点
- **零依赖的本地后端** — 只用 Node 内置的 `node:sqlite`，不装任何三方包

> **核心承诺** — 一张**既生长也遗忘**的知识地图：让记忆变得可见。

## 快速开始

**前置** — Node.js **≥ 22.13**（需要内置的 `node:sqlite`）。

> 为什么不是 22.5：`node:sqlite` 确实在 22.5.0 落地，但一直到 **22.13.0** 才不再需要 `--experimental-sqlite` 启动开关。写 22.5 的话，装在 22.5–22.12 上的人照着下面的命令跑，只会拿到一句「找不到模块 node:sqlite」。

```bash
npm install     # 仅两个开发依赖：Babel standalone、oxlint
npm run serve   # 启动本地后端 + 静态托管
```

打开 **http://localhost:8756/ui_kits/stellar-raft/** 即可点击体验完整应用。

### 默认管理员账户

服务器**首次启动**（新装数据库）会自动入户一个管理员账号，凭据同时打在控制台上：

| | 出厂值 |
| --- | --- |
| 用户名 | `admin` |
| 密码 | `stellar-admin` |

登录后侧边栏底部会多出 **星港管理台** 入口。这组凭据是公开知识——它就写在这份 README 和启动日志里——所以**第一次用它登录，星图会当场拦下你**，要求把用户名与密码一起换成只有你知道的一组（见下方 [出厂凭据交接](#出厂凭据交接)）。

想从一开始就不存在出厂凭据，在**第一次启动前**用环境变量指定自己的：

```bash
SR_ADMIN_USER=captain SR_ADMIN_PASS='换成你自己的强密码' npm run serve
```

这样入户的账号不算出厂凭据，不会被请去交接。

> 管理员只种一次：种过之后即便这个账号被删，也不会自动重建（免得删号后幽灵复活）。已有的库想另起一位管理员，到管理台的**旅客**分区把任一账号任免为管理员。

**环境变量**

| 变量 | 作用 |
| --- | --- |
| `PORT` | 监听端口（默认 `8756`） |
| `SR_DB` | 数据库落点（默认 `server/stellar.db`；父目录不存在会自动建出来） |
| `SR_ADMIN_USER` / `SR_ADMIN_PASS` | 首次启动时的管理员凭据（指定过就不是出厂值，不会被请去交接） |
| `SR_HOST` | 监听地址（默认 `127.0.0.1` 只听本机；`0.0.0.0` = 同一网络下的手机 / 平板也能打开） |
| `SR_TRUST_PROXY=1` | 信任 `X-Forwarded-For` 首跳作为来源 IP（**反向代理后必开**） |
| `SR_GUEST_PER_IP` | 每 IP 游客数初值（默认 `1`，`0` = 不限；之后以管理台设置为准） |
| `SR_GUEST_GATES=off` | 四项功能门禁的初值整体关掉（默认全开） |

> 部署时把 `SR_DB` 指到数据盘，升级换代码就不必搬数据；本地想同时跑第二个实例做验证，给它一份临时库即可，不会碰到手上这份：
>
> ```bash
> PORT=8757 SR_DB=/tmp/probe/stellar.db npm run serve
> ```

### 从手机 / 平板打开

整套断点与手势是为触摸屏写的，但服务器默认只听 `127.0.0.1` —— 手机连不上，那套布局只能靠缩浏览器窗口看。让它听得见局域网：

```bash
SR_HOST=0.0.0.0 npm run serve
```

启动日志会把同一网络下的设备该访问的地址直接打出来，不必自己去翻 `ifconfig`：

```text
[stellar-raft] http://localhost:8756/ui_kits/stellar-raft/  (静态 + API · 数据库 server/stellar.db)
[stellar-raft] 同一网络下的设备：http://192.168.0.158:8756/ui_kits/stellar-raft/
[stellar-raft] 注意：http:// 的局域网地址不是「安全上下文」，浏览器会关掉剪贴板等 API（星图已各自备好退路）。
```

**两件要知道的事**

- **它真的把门打开了** — 局域网里任何人都能访问，而星图对未注册的访客本来就是开放的（每 IP 一位游客）。自己家里、宿舍里没问题；咖啡馆的公共 Wi-Fi 上就别了。默认值之所以是 `127.0.0.1`，就是不想让这件事悄悄发生。
- **`http://` + IP 不是「安全上下文」** — 浏览器会在那里直接抹掉 `navigator.clipboard`、`crypto.randomUUID` 这类 API。星图各自备了退路：复制走 `execCommand` 老办法并**如实回答成没成**（以前是不管成不成都弹「已复制」），匿名令牌退回 `Math.random` 生成。想要完整体验就给它一个 https 反代。

**手机上这套界面是另一套，不是缩小版**

| 在手机上 | 怎么处理 |
| --- | --- |
| 260px 的常驻侧栏会吃掉七成版面 | 最常去的四处沉到底部标签栏（拇指够得着），完整侧栏收进左侧抽屉——抽屉装的就是桌面那一份，不做第二套导航 |
| 六列的笔记表格摆不下 | 每行改成一张卡：标题一行、记忆条一行、星域/复习/连接一行。这条按「网格还撑不撑得住」判（≤1180px），不按「是不是手机」——iPad 竖屏与手机横屏都在那一段里 |
| 编辑器右侧的知识栏没地方放 | 收进底部弹层，头部多一枚按钮。大纲 / 连接的星 / 反向链接 / 记忆 / 在星图中定位 / AI 助手，一块不少，且与桌面共用同一份栏体 |
| 星点在屏幕上只有 4~12px | 触摸端铺一层透明热区，按 `44 / 缩放` 算，缩放到哪一档都还是屏幕上的 44px |
| 输入框字号小于 16px | 触摸端一律抬到 16px——不是为了好看：iOS 会为了凑那 16px 把整页放大，而且不会自己缩回来 |
| 刘海与 Home 指示条 | `viewport-fit=cover` 铺满，再用 `env(safe-area-inset-*)` 把顶栏、标签栏、编辑器状态栏各自让回来 |

**别的平台差异也一并抹平了**

| 差异 | 处理 |
| --- | --- |
| 旧版 iOS Safari（≤17）不认无前缀的 `backdrop-filter` | 每一处玻璃都配了 `-webkit-` 前缀。少了它不是「少个效果」，是整块玻璃变成半透明色块、换一副面孔——`responsive.test.js` 盯着这条 |
| Windows 的 `core.autocrlf` 会把 LF 换成 CRLF | `.gitattributes` 全仓 `eol=lf`。构建产物的哈希是按**文件字节**算的，换行一变，`npm run build:check` 会报一整片「漂移」，而源码一个字没改 |
| macOS 说 ⌘、Windows / Linux 说 Ctrl | 快捷键提示由 `SRKeys` 按系统给词，按键处理本来就 `metaKey \|\| ctrlKey` 双收 |
| 查找高亮依赖 CSS Custom Highlight API | 不支持的浏览器上退化成「跳转即选中」，功能不塌 |

### 这台服务器端出什么

进程的根目录就是整个仓库——数据库、`.git`、`node_modules`、测试与全部源码都在里面。静态托管走**白名单**，只有这几处出得去：

```text
ui_kits/  components/  tokens/  assets/  docs/  guidelines/
styles.css  _ds_bundle.js  _ds_manifest.json
```

其余一律 404（不是 403——「这里有没有东西」本身就不必回答）。点开头的路径（`.git` / `.env` / `.github`）整条挡掉，扩展名也是白名单：MIME 表里没有的类型不出门，公开目录里哪天多出一个 `.db` 也端不出去。

> 为什么要这么严：进程只监听 `127.0.0.1`，看起来谁也够不着。但推荐的部署方式是放在 nginx / Caddy 后面，反代会把 `/server/stellar.db` 原样转进来——那是整库：密码哈希、所有人的笔记正文、会话令牌、分享密文。`tests/static.test.js` 盯着这条边界，两侧都测：该出的一样不少，不该出的一样不漏。

### 几条安全底线

每一条都有测试盯着，改坏了 CI 当场红。

| 底线 | 怎么做到的 | 谁盯着 |
| --- | --- | --- |
| 一条请求打不死进程 | 整条管线套 try：`GET /%ZZ` 曾让 `decodeURIComponent` 抛 `URIError`，在 http 回调里就是 uncaughtException，进程当场退出——一个未认证的 GET 不该有这种分量 | `security.test.js` |
| 密码经得起磨 | scrypt（16 字节随机盐 · 64 字节输出 · `timingSafeEqual` 比对）；登录节流两本账（IP 50 次 / 账号 6 次，15 分钟窗口） | `throttle.test.js` |
| 耗时不出卖账号 | 查无此人也陪跑一遍同样重的哈希——否则「几毫秒 vs 几十毫秒」就把「这台服务器上有哪些账号」说了出去 | `security.test.js` |
| 登录态有寿命 | 90 天没露面就地失效并删行；失效令牌明说「请重新登录」，不悄悄变成一位新游客 | `resilience.test.js` |
| 令牌不进 URL | 只认 `Authorization` 头；`?token=` 仅对 sendBeacon 与备份下载两个够不着请求头的入口开门——URL 里的令牌会顺着 Referer、反代日志、浏览器历史一路留下来 | `security.test.js` |
| 报错不泄底 | 500 的正文永远是同一句话，sqlite 库表结构与文件绝对路径留在服务器日志里 | `security.test.js` |
| 笔记正文永不出库 | 访客视图由服务端逐字段重建（只有星名 / 结构 / 大纲），而不是「删掉几个字段再发出去」 | `server.test.js` |
| 富文本不带电 | 白名单清洗器（标签 / 属性 / style / 协议），30 条攻击样本按**浏览器最终解出的协议**判，而不是按字符串里有没有那个词 | `sanitize.test.js` |
| 运行时来路清楚 | 五个 CDN 脚本版本全部钉死并带 `integrity` + `crossorigin`——被投毒或中途改写时脚本直接不执行 | `security.test.js` |
| 畸形输入只换来 4xx | 请求体是 `null`、数组、类型全错，一律 4xx；ID 先收成整数再进 SQL | `server.test.js` |
| 坏快照拖不垮任何人 | 快照里数组的每个成员也逐层校验（null、字符串、类型全错的星/星域/连线），一颗坏星不能让造访者吃 500、更不能让管理台瘫掉 | `server.test.js` · `admin.test.js` |
| 导入不设炸弹 | Markdown 仓库导入有界：zip 条目数封顶、解压后总量封顶、单文件限 64MB——zip 炸弹炸不开标签页 | `vault.test.js` |
| 隐身只有主人能解 | 访客被「对 TA 隐身」后，移除好友再拿同一段密文重新兑换也洗不掉标记——解除权只在主人手里 | `server.test.js` |

## 记忆模型

每颗星维护一组状态 `sr = { S 稳定度, last 上次复习, lit 点亮时刻, ember 熄灭时刻 }`。

**可提取率** `R = exp(−Δt天 / S)` 直接作为亮度——每次打开、每次切视图、每分钟心跳，都按真实时间重算。你不复习，星就真的会暗下去。

```
亮度 R = exp(−Δt / S)        冷蓝（正在遗忘）→ 暖金白（已掌握）
复习成功  S ×= 增长因子 + (1−R)·0.6
复习失败  S ×= 0.45
稳定度上限  曾点亮 365 天 · 从未点亮 60 天
```

**点亮**是一条独立于亮度的认证轴——一颗星要在费曼模式里被「讲透」才算真正点亮。点亮的星同样会衰减，低于阈值熄灭为「待重燃」的余烬态。

**四档复习策略**（真实驱动到期队列与桌面通知）：随星变暗（遗忘曲线）· 1·3·7·15 天间隔阶梯 · 每日固定 · 不提醒。

## 设计哲学

星图是一件*作品*，不是又一个白底办公笔记本。四条美学法则贯穿始终：

1. **每个视觉元素都承载信息，而非纯装饰** — 亮度=记忆强度 · 大小=重要度 · 距离=关联度 · 色温=年龄。美，必须*可读*。
2. **少即是多** — 全局 ≤ 3–4 种色相，无彩虹、无卡通、无拟物俗气。
3. **暗场优先** — 大胆的黑色负空间，低信息密度，留出呼吸的余地。空账户几乎全黑，**知识是唯一被引入的光**。
4. **编辑器专业可用第一，美观第二** — 但美从不掉线。

## 功能全景

### 知识本身

- **会遗忘的知识星图** — 记忆强度按真实时间衰减，直接驱动每颗星的亮度与色温。
- **费曼内化点亮** — 讲透一颗星，它才真正亮起来（金色高潮瞬间）。
- **间隔重复复习** — 到期卡片三档自评（忘了 / 模糊 / 记得），闭环驱动稳定度增长。
- **时间之窗** — 体检页预演未来 7 天哪些星将熄灭或到期，一键排入复习；把遗忘从**事后发现**变成**事前预警**。16 周观星热力图与连续天数由时间线实时派生。

### 写与读

- **全套界面** — 星图主界面 · 亮度鸟瞰 · 三维星系（Three.js）· 费曼抽屉 · 列表管理 · 时间轴 · 复习会话 · 收件箱 · 黑洞回收站 · 星际漫游 · 知识体检 · 专业块编辑器。
- **专业块编辑器** — H1–H3 / 待办 / 列表 / 引用 / 代码 / LaTeX / 表格 / 图片，markdown 即时转换、⌘F 查找替换、反向链接与大纲、应用级撤销/重做（输入按突发合并、换块各自封口）。打 `[[` 唤出选星器插入星链接；选中一段文字粘一个网址即成链接；剪贴板里的截图直接落成图片块；正文里的星链接单击即前往那颗星，外链新标签页打开。
- **知识可进可出** — ⌘K 全文搜索直达笔记正文（片段高亮）；一键导出 Obsidian 风格 Markdown 仓库（zip，零依赖打包），也能把 .zip / 一批 .md **反向导入**长成星空（文件夹→星域、frontmatter→属性、`[[wikilink]]`→连线，增量并入不覆盖）。导入导出与真实 GFM 完全互逆，对齐 GitHub · Typora · Obsidian——两端都过属性化模糊测试（数千例随机块 + 对抗输入）：往返不丢内容，括号密集的恶意文本也冻不住页面（链接正则做了防回溯）。
- **插图有分寸** — 星图是「整片星空一次整存」，笔记里的图以 dataURL 内联在快照里跟着每次保存整体上传。所以大图进笔记之前先压：小图原样保留，大图按长边 1600px 缩一次并逐档降质（webp 优先，保住透明通道），GIF / SVG 不重编码只判大小，实在压不下的明说一声。少了这一步，一张手机原图就能让整片星空越过服务器 8MB 上限与 localStorage 配额，此后每次保存都失败——而用户只会看到一句「服务器暂不可达」。
- **按 `?`** 随时弹出全站快捷键速查面板。

### 社交与 AI

- **星际漫游与知识共鸣** — 用星语密文造访好友星系（服务端裁剪，**笔记正文永不出库**）；造访时自动高亮你们共同拥有、甚至都点亮过的知识；可留一句星语、赠星、收纳；主人可见访客足迹与来信。
- **真实 AI 接入** — 配置 OpenAI / Anthropic / 自定义网关（one-api、Ollama 等）后，费曼「AI 学生」由所配模型真实追问，编辑器可生成摘要、推荐标签、建议跨星域连接。未配置时优雅回退本地规则学生。

### 账号与工程

- **账号与多设备** — 用户名 / 邮箱登录（scrypt + sessions）；注册把当前匿名星空**原地收进账号**，一颗星都不丢；切换账号时本机密钥等痕迹全部清理。
- **多设备同步比因果，不比时钟** — 乐观锁版本号。本机镜像记下「这份内容基于服务器的第几版」与「有没有被确认过」：启动时别处没人写过，离线攒下的编辑为准并回推；另一台设备写过，服务器为准。两台设备的系统时钟谁快谁慢，不再左右谁赢。409 收敛不再把刚对齐的版本原样推回去（冲突不放大），防抖飞行途中也不再自撞。
- **会话有寿命** — 90 天没露面的登录态在下次被使用时就地失效并从库里删掉（此前这只是管理台上一颗没人点的按钮，两年前泄漏的令牌照样通行）。失效的令牌不会被当成匿名令牌新建一位游客——那会让被强制下线的人对着一片崭新的空星空发愣，还白占一个游客名额；现在明说「这台设备的登录已失效」，并给一颗「重新登录」。
- **崩了也说人话** — 整个应用与每个视图各有一层错误边界。零构建的代价是任何一个组件抛异常就会卸载整棵树；现在换成一张卡：出了什么事、你的星空没事、怎么回去（回到星图 / 刷新 / 复制诊断信息），而不是一整屏无从解释的黑。
- **出厂凭据交接** — 出厂管理员第一次登录会被一张关不掉的卡拦住：用户名与密码一起换，还要亲手勾上「我已记下」；交接的同时吊销这个账号的全部会话。
- **登录节流** — 密码前面这道门是公网部署时唯一一道门：服务端为登录记两本账（来源 IP 与账号标识），同一账号连败 6 次、或同一 IP 15 分钟内攒够 50 次失败，就先停一会儿（429 + 还要等多久）。停的是「再试一次」而不是账号，窗口一过自己就开；登录成功即两本账一起销。
- **新手引导** — 首次打开自动弹出的 11 页导览册 + 末页聚光实地导览，随时可在设置里回看。
- **零构建 · 零依赖** — 浏览器内 Babel 编译 JSX；后端仅用 Node 内置 `node:sqlite`。

## 移动端

整套 kit 原本按 1440×900 桌面画。现在一套断点贯穿全站——手机上换的是**布局与手势**，不是另做一个阉割版。

| 断点 | 宽度 | 布局 |
| --- | --- | --- |
| `phone` | ≤ 720px | 侧栏收进左侧抽屉 · 底部标签栏（星图/列表/复习/收件箱/更多）· 顶部条 · 视图单列 · 弹层铺满 |
| `tablet` | ≤ 1024px | 侧栏可折叠 · 编辑器右侧知识栏让位 |
| `desktop` | > 1024px | 原本的桌面布局，一切照旧 |

**手势** — 星图从鼠标事件整体换成指针事件，触摸这才真的能用：

| 动作 | 手机 | 桌面 |
| --- | --- | --- |
| 平移画布 | 拖动空白 | 拖动空白 |
| 缩放 | 双指捏合 | 滚轮 |
| 新建星域 / 知识星 | 长按空白 520ms | 右键 |
| 移动一颗星 / 整个星域 | 拖动星点 / 主星 | 同左 |
| 看某颗星 | 点一下（摘要卡贴屏底，不挡星空） | 点一下（卡片跟着星） |

**几处刻意的取舍**

- **不禁用捏合放大** — `user-scalable=no` 是无障碍红线。星图自己的缩放走双指手势，与浏览器缩放并不冲突。
- **安全区集中在 `--sr-safe-*` 四个变量里**，组件不各自写 `env()`；顶部条吃掉刘海、底部栏吃掉 Home 条，视图拿到的是一块干净矩形。
- **`100vh` 会被地址栏吞掉** — 优先 `100dvh`，老浏览器退回实测的 `--sr-vh`。
- **断点只有一处真源**（`responsive.js` 的 `SRScreen`），组件一律 `SRKit.useScreen()`；测试里有一条专门盯着「有没有人偷偷自己写 matchMedia」。
- **编辑器不挂底部标签栏** — 键盘弹起时它只会碍事，返回入口在编辑器自己的顶部。

## 星港管理台

登录管理员账号后，侧边栏底部会出现 **星港管理台**（只有管理员看得见）。管理员在应用里与普通用户**完全一样**——一样建星、点亮、复习、漫游；管理台只是多出来的一层。

### 出厂凭据交接

出厂管理员用 `admin` / `stellar-admin` 登进来的那一刻，一张**关不掉的交接卡**会盖住整个应用：

- **用户名与密码一起换** — 只换密码不够。出厂用户名同样是公开的，留着它等于把门牌号也交出去，攻击者省下的正是「先猜中是谁」这一步。两样都由服务端在同一个接口里校验：出厂用户名（不分大小写）、出厂密码、与用户名雷同的密码一律拒收，管理员密码下限是 **8 位**（普通账号 6 位）。
- **必须亲手勾上「我已经把这组凭据记下来了」** — 勾上之前提交键是灰的。星图不存找回邮箱、也不发重置邮件，这组凭据忘了只能到服务器上改数据库里的那一行。卡上另有一枚「复制这组凭据」，交给密码管理器最省事。
- **交接即吊销全部会话** — 包括你此刻正在用的这一把。出厂凭据是公开的，别处可能早就拿它登进来了；服务器改完当场清空这个账号的会话表，只发一把新钥匙给你这台设备，其余一律被请回登录页。
- **唯一的出口是「退出登录」** — 误登进来的人不该被困住，但也没有绕过去这条路：没有 Esc、没有点遮罩、没有关闭按钮。

交接完成后，出厂凭据的两样都立刻作废，管理台顶部那条红警告随之摘掉，操作日志里留下一条 `admin.handover`。这道门只开一次——交接过的星港再调这个接口只会拿到 409。

> 这张卡拦的是**人**，不是接口：前端的模态挡不住改 JS 的人。它真正的作用是让「换掉出厂凭据」从一句写在 README 里的建议，变成一件不做就走不下去的事。服务端那一侧的硬保证是另外三条：每个 `/api/admin/*` 独立鉴权、登录节流、交接接口只认真实会话里的管理员身份。

**八个分区**

| 分区 | 能做什么 |
| --- | --- |
| **总览** | 账号构成 · 全站星数与点亮数 · 近 14 天新到访/注册/登录趋势 · 游客与来源 IP · 分享与来信 · 进程与磁盘 · 站点开关现状，每 10 秒刷新运行读数 |
| **旅客** | 搜索（名字/用户名/邮箱/IP）、筛选、排序、分页；展开任一行看这个人的星域分布、记忆强度、来源 IP、最近登录、分享、访客与会话；停用、任免管理员、重置密码、改资料、强制下线、级联删号 |
| **游客** | 按来源 IP 聚合的匿名游客名单 · 每 IP 限额调节 · 四项功能门禁的逐项开关 · 一键清理「从没存过星系且 7 天没露面」的空账号（存过东西的一个都不动） |
| **分享** | 全站谁把星系开给了外面、开到什么程度、有多少访客；可强制关闭（密文保留，主人能自己再开） |
| **会话** | 每台登录过的设备；令牌只出一段指纹，完整令牌永不出库 |
| **广播** | 全站公告（三档语气 + 实时预览，用户读过一次就不再打扰）· 新账号注册开关 · 维护模式 |
| **系统** | 数据库体积明细 · 一键备份下载（完整 `.db`）· 收拢 WAL · VACUUM 压缩 · 清理过期会话 |
| **日志** | 每一次停用、删号、改密与站点变更的审计留痕（保留最近 2000 条） |

每个数字都由服务端当场从库里算出，不估算、不抽样。

被缓存的只有**解析结果的形状**——每颗星里参与计算的那几个字段，按快照版本号判新鲜，任何一次保存都让它当场作废。亮度、点亮、熄灭这些随时间变的量仍然每次请求现算：同一片星空，隔十分钟再看就该更暗一点，这件事不能被冻在上一次保存的那一刻。

> 这不是洁癖，是量出来的：300 个账号、46MB 快照时，总览与旅客名单原本各要 **273ms**——而总览每 10 秒轮询一次。Node 是单线程的，那 273ms 里全站所有人的请求都在排队。现在总览 **6ms**、名单 **1ms**。省下来的是三件事：不再为每次请求把每个人的快照重新 `JSON.parse`；元信息查询走覆盖索引，根本不碰存着正文的表页（`LENGTH(data)` 一个函数就占了 37ms——它要扫完 46MB 数字符）；名单的星系读数只给真正出库的那 20 行算。

**几条硬规矩** — 管理员不能停用或删除自己；最后一位管理员不能被撤职；要停用或删除另一位管理员，得先撤销对方的管理员身份；删号要求原样敲一遍对方用户名；停用即刻踢下线，被停用的人只剩「退出登录」这一条路。

> 每个 `/api/admin/*` 在服务端都有独立守卫——把前端的布尔值改成 `true`，拿不到任何数据。

### 游客与功能门禁

**每个 IP 一个游客** — 同一来源地址上只允许存在一个未注册的匿名账号。第二位访客会被拦下并被请去登录或注册；注册之后账号不再算游客，这个 IP 的名额立刻空出来。限额在管理台的**游客**分区里可调（填 `0` = 不限）。

> **反向代理下必读** — 星图默认按 socket 直连地址判定来源。跑在 nginx / Caddy 后面时所有请求都长着 `127.0.0.1`，游客限额会把整台服务器锁成一个游客，登录节流也会把所有人当成同一台机器算失败次数。这种部署要用 `SR_TRUST_PROXY=1` 启动，改读 `X-Forwarded-For` 的第一跳——**前面确实有你自己的代理时才开**，这个头是可以伪造的。

**四项功能需要账号**（默认全开，可逐项关闭）

| 门禁 | 拦在哪 | 为什么 |
| --- | --- | --- |
| 写笔记 | 前端入口 | 笔记是要长期回来看的东西，值得有个能带走的账号 |
| Markdown 仓库进出 | 前端入口 | 整片星空的批量导入导出 |
| 分享星系 | **服务端硬拦** | 密文发出去，别人就能循着它找到你——先得有个主人 |
| 星际漫游 | **服务端硬拦** | 造访会在对方星系留下足迹，也让对方能回信 |

游客点到受限功能时，不会看到坏掉的按钮，而是一张说明卡加一句「注册会把你现在的星空原地收进账号，一颗星都不会丢」，登录页随即递到手边。

## 项目结构

```text
stellar-raft/
├─ styles.css              # 消费者唯一需要引入的入口（仅 imports）
├─ tokens/                 # 设计令牌：colors · spacing · typography · effects · themes(黎明 Dawn)
├─ assets/                 # <sr-starfield> 星场 web component + SRConnect 连接曲线
├─ components/             # 18 个可复用原语 · core / knowledge / overlay / form
├─ ui_kits/stellar-raft/   # 可交互 App（全套视图 + 管理台 · 三档断点 · 记忆模型 · 点亮/复习 · 持久化）
├─ server/                 # 零依赖本地后端（node:sqlite）
│   ├─ server.js           #   请求管线：解析身份 → 封禁/维护/门禁三道闸 → 派发路由
│   ├─ config.js           #   端口、路径、数据库落点（只读环境变量）
│   ├─ db.js               #   建表、旧库迁移、全部预编译语句
│   ├─ core.js             #   跨路由共用：应答 · 身份 · 站点设置 · 审计 · 记忆衰减 · 投递
│   ├─ seed.js             #   新装库的种子：演示好友与默认管理员
│   └─ routes/admin.js     #   星港管理台（/api/admin/*，进门先过权限守卫）
├─ docs/                   # 零构建静态文档站 + 截图 + 架构图
├─ guidelines/             # 15 张基础规范示例卡（颜色 / 字体 / 间距 / 图标 / 品牌）
├─ scripts/                # build · lint（产物由源码生成，勿手改 _ds_bundle.js）
└─ tests/                  # node --test：29 个套件（server / auth / admin / responsive / compile / tokens …）
```

**组件库** — 18 个原语挂在命名空间 `window.StellarRaftDesignSystem_2866af`：

- `core/` — Icon · IconButton · Button · GlassPanel · Badge · Tag · Input
- `knowledge/` — MemoryBar（+ memoryColor）· StarNode · ConstellationItem
- `overlay/` — Modal · Toast（+ 命令式 `toast()`）· Tooltip · ContextMenu
- `form/` — Select · Switch · Checkbox · Tabs
